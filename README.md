# riyadh-vacant-land-pricesتحليل أسعار الأراضي الفضاء في الرياض  Riyadh Vacant Land Market Analysis

مشروع تحليل للأراضي السكنية في مدينة الرياض واكتشاف الفرص الاستثمارية باستخدام Python, SQLite, وTableau Public، مطبقاً منهجية Ask, Prepare, Process, Analyze, Share, Act.

 ملخص المشروع (Executive Summary)
تم جمع وتتبع 308 إعلانات بكود برمجي مصمم خصيصا لقشط بيانات الإعلانات للأراضي الفضاء للبيع في مدينة الرياض ، بعد عمل قاعدة بيانات بالاعلانات قمت بعملية تنظيف البيانات باستخدام  Python ووصلت بعد التنظيف إلى 183عينة نهائية صالحة للتحليل تضم إعلاناً (136 سكنياً و47 تجارياً). كشف التحليل أن 63% من المعروض يتركز في قطاعي الغرب والشرق، بينما الأحياء الراقية في الشمال (الملقا، النرجس، الياسمين) شبه مبنية بالكامل. وبناءً على محرك فرز هرمي متطور، تم استخراج 7 فرص شراء حقيقية عالية الثقة (5.8%) مسعّرة بأقل من 25% تحت وسيط حيّها.
